No redirect needed

  • preventDefault() stops the browser's native form submission
  • JS updates the DOM in place — no navigation, so there's nothing to redirect away from

Data, not HTML

  • Server returns application/json (201/200), HTML comes from static files
  • Rendering moved from render_page() on the server to renderTodos() in the browser

Refresh still works

  • The server's todos.json stays the source of truth
  • Reload → index.html + client.js load again → loadTodos() fetches fresh data
