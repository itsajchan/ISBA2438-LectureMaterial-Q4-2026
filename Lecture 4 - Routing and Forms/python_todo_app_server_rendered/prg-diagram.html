With the 303 redirect (this app)

  • POST handles the data, then replies 303 + Location: /
  • Browser lands on GET / — address bar shows localhost:8000/
  • Refreshing = plain GET → no duplicate todos
  • No "confirm form resubmission?" warning

Without a redirect (anti-pattern)

  • POST renders the HTML itself with 200 OK
  • Address bar stuck at /add-todo
  • Every refresh re-sends the POST → duplicate todos
  • Browser shows "Confirm form resubmission?" dialogs

The three lines that do it — server.py:91-93

self.send_response(303)
self.send_header("Location", "/")
self.end_headers()
